# Pool Example

Программа запускает 30 долгих задач в `ThreadPoolExecutor` с тремя потоками и очередью на 3 задачи.

## В чём была ошибка

Очередь ограничена тремя задачами, а потоков тоже три. Пока три задачи выполняются, в очередь влезает ещё только три. Седьмая задача уже не помещается, и `submit` выбрасывает `RejectedExecutionException` — программа падает и не выполняет остальные задачи.

Вторая проблема: после цикла не было `shutdown()`. Потоки пула не завершались, и программа висела даже если задачи доходили до конца.

## Как исправлено

- Добавлен свой `RejectedExecutionHandler`: если очередь заполнена, поток, который создаёт задачи, не падает, а блокируется на `queue.put(task)` и ждёт, пока в очереди освободится место. Все задачи в итоге выполняются внутри пула, в трёх потоках, и одновременно выполняется не больше трёх задач.
- В конце вызываются `shutdown()` и `awaitTermination()`, поэтому программа дожидается выполнения всех задач и корректно завершается.
- Параметры пула не менялись, как и требовалось.

## Запуск

```
javac -d out src/PoolExample.java
java -cp out PoolExample
```

## Результат

В выводе 30 строк `creating`, 30 строк `start` и 30 строк `end #… done tasks: 30`. Значение `in progress` никогда не превышает 3, а последняя задача завершается с `done tasks: 30`.
